# 本機自動化地圖 · Local Automation Map

公開儲存庫：https://github.com/Ming050823/local-automation-map

這是一份可直接在瀏覽器開啟的說明頁，對應 `automation-prompt-local.md`：從訪談需求到在自己電腦上排程執行。頁面支援中／英切換，並可複製完整 Prompt 原文。

## 把 HTML 上傳進這個儲存庫

1. 打開 https://github.com/Ming050823/local-automation-map/upload/main
2. 把 `index.html`（或 `local-automation-map.html` 改名為 `index.html`）拖進頁面
3. 下方 Commit 選 **Commit directly to the `main` branch**，按 **Commit changes**

上傳完成後，可用這個預覽網址（GitHub 本身不會把 `.html` 當網頁開）：

https://htmlpreview.github.io/?https://github.com/Ming050823/local-automation-map/blob/main/index.html

## 開啟 GitHub Pages（建議）

1. 打開 https://github.com/Ming050823/local-automation-map/settings/pages
2. Source 選 **Deploy from a branch**
3. Branch 選 `main`，資料夾選 `/ (root)`
4. 按 Save

約一分鐘後公開網址：

https://ming050823.github.io/local-automation-map/
